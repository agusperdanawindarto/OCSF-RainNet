# Proposed availability statements (author verification required)

**Data availability:** The rainfall-intensity supervision uses NASA GPM IMERG Final V07B (DOI: https://doi.org/10.5067/GPM/IMERG/3B-HH/07). Himawari-9 AHI Band 13 L1b HSD observations are available from the NOAA Himawari-9 open-data archive subject to upstream terms. A processed paired dataset covering 127 scenes from 32 dates is stored in a private Kaggle dataset at https://www.kaggle.com/datasets/agusperdana/ocsf-rainnet-calibrated-2024. Because this processed dataset is private, its accessibility must be explicitly described to the editor and data access arranged through the responsible author; public access is not claimed. Scene-level provenance and split tables are in this repository.

**Code availability:** Analysis, training and processing scripts, executed notebook definitions, trained model checkpoints and summary evaluation artifacts are distributed at https://github.com/agusperdanawindarto/OCSF-RainNet (cite the relevant version/commit). Large per-scene prediction archives and the source data binaries are retained in private research storage.

**Scientific limitations:** Comparisons assess agreement with the satellite IMERG supervision and not independently observed ground rainfall. Full event independence and overlap with the historical pretrained backbone remain to be independently audited.

These are draft statements and require all authors to confirm data distribution rights and whether private processed data access meets the journal's review requirements.
